# 随机写真融合版

整合「孙琳雪随机场景融合版」（人物前缀＋最大变量池）、「vibeshot-candid-photography」（通用主体＋同源变量池）、「色狼视角角色摄影」（偷拍感模式）三方而成。所有随机变量池已合并去重，独有项互相补全，同一套池子可配任意人物前缀使用。

## 安全红线（强制）

- 所有角色必须明确为成年角色，输出提示词必须包含"成年"限定。
- 偷拍感模式为虚构、摆拍、电影化模拟效果，只使用偷拍摄影的视觉语言；不涉及真实人物隐私侵犯、真实非自愿偷拍。
- 场景只使用公开或半公开空间；禁止厕所、更衣室、浴室、卧室等私密空间窥视。
- 服装默认完整穿着；不设计任何暴露、性暗示或色情内容。
- 禁止未成年角色，任何二次元/虚构角色都按成年人处理。

## 加载顺序（每次调用必须按序执行）

1. 用户提供了可执行写真参数（人物/场景/服装/数量等）？→ 直接执行任务。仅当"首次使用/帮助请求/无参数调用"时，读取 `references/人物层.md` 并输出精简引导（不展开完整教程）。
2. 读 `references/人物层.md`：确定人物前缀（默认孙琳雪 / 自定义 / 通用主体）、脸部一致性保护、通用负面词。
3. 判断模式：
   - 用户提到"偷拍感 / 色狼视角 / 被抓拍 / 偷拍 / 隐蔽视角"→ **偷拍感模式**，读取 `references/偷拍感模式.md`。
   - 否则 → **常规随机模式**，跳过偷拍感模式文件。
4. 按需读取变量池文件：
   - `references/变量池-形象神态.md`（发型/发色/饰品/表情/气质眼神/视线/表情手势）
   - `references/变量池-服装场景.md`（服装/性感度/场景/背景补全/瞬间状态）
   - `references/变量池-摄影语言.md`（景别/焦段/机位/构图/前景/光线/色彩/摄影状态/图片风格/正文表达）
   - `references/变量池-导演路线.md`（导演式摄影企划路线池/气质叠加池，按 1/2 概率抽路线、1/3 概率叠加气质）
   - `references/成像机制原则.md`（整体质量规则，默认执行：主成像系统唯一、光线来源→落点→结果、皮肤纹理与反射分开写等）
5. 按「Prompt 生成方式」组织最终提示词。
6. 按「输出格式」交付。

## 模式路由

### 常规随机模式（默认）

从各变量池随机抽取组合，产出真实生活摄影感、偶然抓拍感、非常规机位、强烈空间层次的人像写真。无固定机位/构图倾向，全池自由。

### 偷拍感模式

在常规随机基础上替换以下维度，其余照常随机：

- 机位改为从偷拍机位库抽取（障碍物后/远距离长焦/手机随手/低机位/缝隙/反射）。
- 前景障碍物占据画面 15%～40%，前景自然侵入并形成遮挡。
- 动作从"正在做事情被拍到"池抽取，不用摆拍 Pose。
- 约 20%～30% 概率叠加"被发现"模式（角色侧眼/皱眉/回头看向镜头）。
- 构图遵循不完美原则（裁切、偏移、倾斜、轻微失焦、自动曝光感），但人物面部保持可识别。

## 人物层规则（详见 references/人物层.md）

- 默认：孙琳雪固定前缀，逐字使用，不得改写删减。
- 自定义：用户给出新人物前缀或明确要求换人时，逐字替换前缀，其余规则、变量池、负面词、输出格式全部不变。
- 通用主体：用户要求"韩国INS网红/通用主体/不要指定人物"时，使用"一个极具镜头感的韩国 INS 网红，皮肤白皙，傲人身材"。
- 脸部一致性保护：默认执行（标志性特征轻量句＋全身照点名句），规则详见人物层文件。

## Prompt 生成方式

固定人物前缀（逐字）→ **导演路线判定**（按 1/2 概率从「变量池-导演路线.md」抽 1 条摄影企划路线；抽中则场景/服装/光线/成像按路线方向走，未抽中按常规池）→ 随机发型发色饰品 → 表情与服装风格 → 场景（路线或场景池）→ 正在发生的瞬间 → 景别与焦段 → 机位 → 构图 → 前景遮挡 → 光线（路线或光线池）→ 色彩 → **气质叠加**（按 1/3 概率从气质叠加池抽 1 个）→ 图片风格（每组必选；抽中路线时以路线自带成像/滤镜为准，不再重复抽图片风格池）→ 摄影状态 → 整体摄影要求（含负面约束）。

- 偷拍感模式下，机位/构图/前景/动作按偷拍感模式规则替换，并叠加"被发现"概率；路线判定照常，偷拍感优先。
- 成像机制原则（见 references/成像机制原则.md）默认执行：一张图只保留一个主成像系统，光线按"来源→落点→结果"写，皮肤纹理与反射分开写，妆容只写最小可识别锚点，场景与道具拆开写，动作写骨架，元素互相认识，用户指定主题色时跨模块锁定。
- 不要机械逐项罗列，允许模型对细节合理自由发挥；变量池提供方向，不要求把抽中的每个词原样写进最终提示词。
- 正文采用短句堆叠＋留白的意境化写法（见变量池-摄影语言.md「正文表达」），必备信息（前缀/保脸句/场景/图片风格句）仍须保留清楚。
- 每组必须包含一个明确的图片成像风格句。

## 输出格式

默认直接输出，每组包含三部分：

1. 要素卡（代码块外）：标题 + 服饰 + 场景 + 动作——标注该组抽中的三要素；标题用一句有画面感的话概括核心瞬间。
2. 一个代码块（text）：完整提示词 + 换行 + 负面提示词，正面负面一体，一次复制即完整一套。
3. 负面提示词：以「负面提示词：」开头，后接通用负面词＋该组自带具体负面。

- 多组时编号 `### 01 / ### 02`，编号写在要素卡前；单组不编号。
- 完整提示词必须为一段连贯自然语言，不得使用「服饰：/场景：/动作：」字段结构。
- **中英文双版本（默认执行）**：每组同时输出中文版和英文版两个代码块。中文块在前，英文块在后；英文版是中文版的忠实翻译，服装用词严格走「服装场景.md / 安全替代词典」里的安全英文词，开头自然嵌入 High fashion editorial / Boudoir photography / Avant-garde couture / Cinematic aesthetic 之一作为艺术氛围护盾。负面词英文版翻译为对应英文。
- 用户要求"只给提示词"则只输出提示词本体（代码块，仍含中英文两版），不输出要素卡。
- 不解释随机到了什么变量，不在提示词之后做摄影分析，不总结每组特点。

## 批次差异规则

多组时每组必须明显不同。优先避免以下变量重复：导演路线、场景、发型发色、瞬间状态、景别、焦段、机位、构图、前景、光线、图片风格。

需要主动混合：近景与大环境；低机位与高机位；广角与长焦；室内与室外；水边、城市、交通工具、建筑空间等不同环境；安静瞬间与动态瞬间。目标是让同一批作品看起来像来自同一个摄影审美体系，但不是同一套模板换衣服。

## 用户指定内容处理

用户指定的任何条件优先级最高。例如指定"荷塘 + BM风 + 28mm + 极低机位"，则锁定这些项，其余维度继续随机。不要修改或替换用户已经指定的变量。用户指定人物时按人物层「自定义人物」规则替换前缀。用户指定画幅（9:16/3:4/1:1 等）时，画幅句放在提示词第一句。
