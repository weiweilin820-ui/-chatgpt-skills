# 人物层：前缀、自定义、保脸、负面词

注意：前缀不使用任何参考图锁脸句；除固定前缀保留的“五官精致自然”一句外，提示词内不展开五官、脸型、头型描写，脸部细节由参考图承担；保脸优先靠参考图与全身照“脸部清晰”句。

## 自定义人物

用户指定其他人物时，以用户给出的前缀/设定为准，其余随机规则、变量池、负面词、输出格式不变。未指定时默认使用孙琳雪前缀。

## 通用主体

```text
一个极具镜头感的成年东亚女性，真实自然的人像摄影主体。
```

## 脸部一致性保护规则

1. 有参考图时，参考图是身份来源，不重新设计人物五官。
2. 全身照、远景、人物小比例构图时加入“脸部清晰、五官细节完整”。
3. 避免大侧脸、极端低头仰头、逆光剪影、面部大面积遮挡、死黑或过曝。
4. 发型、发色、刘海可变化；用户指定时以用户指定为准。
5. 不用大量反向五官词与参考图竞争。
6. 不堆叠“完全一致/绝对不变”等强硬同义句。
