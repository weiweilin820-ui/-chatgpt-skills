# 随机写真融合版 V2

V2 的目标不是“堆更多关键词”，而是让人物身份、摄影企划、镜头、光线和成像系统彼此一致。

## 核心优先级

用户明确指定 > 安全与成年限定 > Identity Lock > 参考图职责 > 场景/故事瞬间 > 摄影机决策 > 光线物理 > 成像系统 > 风格修饰 > 负面约束。

## 1. Identity Lock

### 有参考图
把参考图视为人物身份源。默认保持可识别的面部身份、脸部比例与核心五官关系，不重新设计人物。不要用长串文字五官描述与参考图竞争。

允许变化：发型、发色、妆容强度、服装、饰品、姿态、表情、场景、镜头、光线和摄影风格，除非用户锁定其中某项。

全身/远景时增加一条高信号要求：“人物脸部仍清晰可辨，保留参考人物身份特征”。避免极端遮脸、死黑脸、过曝脸和严重运动模糊。

### 无参考图
才启用文字人物锚点。默认人物可读取 V1 `../随机写真融合版/references/人物层.md`；用户提供人物设定时优先使用用户设定。

## 2. Reference Roles

存在多张参考图时，先在内部给每张图分配职责：Identity（身份）、Outfit（服装）、Pose（动作）、Composition（构图）、Lighting（光线）、Environment（场景）、Style（成像风格）。

同一张图可以承担多个职责，但不得把不同人物参考图的身份特征混合到一个人脸上。用户说“只参考衣服/姿势/场景”时，不把该图当身份源。

## 3. Story Moment

优先生成“正在发生的瞬间”，而不是标准摆拍：刚推门、刚坐下、整理头发、走到一半回头、拿起饮料、风吹起裙摆或外套、看窗外、翻书、等车、下车、穿过人群、收伞、扶栏杆等。

动作必须有清楚身体骨架；避免同时塞入多个互相冲突的动作。

## 4. Camera Director

镜头不是随机孤立词，而是根据故事瞬间选择：
- 24–28mm：强环境、近距离广角、低机位、旅行抓拍。
- 35mm：生活纪实、街头、空间关系。
- 50mm：自然人眼感、中近景。
- 85–135mm：人物突出、背景压缩、安静观察。
- 135–200mm：远距离街头抓拍与空间压缩。

机位与焦段必须匹配。近距离极低机位通常用广角；远距离观察通常用长焦。不要出现“200mm超广角”之类冲突。

## 5. Composition

每组只选一个主构图逻辑：中心稳定、偏心留白、前景遮挡、框中框、极低机位仰拍、高机位俯拍、镜面/玻璃反射、人物小比例大环境、近景侵入、动态裁切。

多组生成时优先改变主构图逻辑，而不是只换衣服。

## 6. Lighting Physics

所有光线按“来源 → 方向 → 落点 → 结果”组织。例如：阴天窗光从左前方进入，落在脸颊、发丝和针织面料上，形成柔和低反差高光；背景接受同方向光线，人物与环境属于同一个空间。

不要同时堆“柔和自然光 + 强硬直闪 + 月光 + 霓虹主光 + 电影顶光”。只能有一个主光逻辑，其他光作为环境辅助。

## 7. Imaging System

每张图只选一个主成像系统：真实手机原相机、CCD/direct flash、35mm film、Pro-Mist柔雾、中长焦高清人像、低调电影摄影。主系统确定后，其他质感词必须服务它。

## 8. Conflict Resolver

生成前做一次内部冲突检查：
- 人物身份描述是否与参考图竞争？
- 焦段是否与机位/距离冲突？
- 主光是否超过一个？
- 成像系统是否互相打架？
- 服装是否与场景、天气、动作明显不协调？
- 构图要求是否互相矛盾？
- 是否为了“高级感”自动把用户要求的手机随拍/偶然抓拍修正成棚拍？

若冲突，保留优先级更高的一项，删除低优先级修饰词。

## 9. Targeted Negative

负面词只针对最可能出现的问题，不无限堆叠。优先：身份漂移、塑料皮肤、过度磨皮、人体/手部错误、服装穿模、错误文字、水印、背景结构错误、与当前成像系统冲突的效果。

用户的正向要求不要又出现在负面词里。

## 10. 随机变量

V2 可继续读取 V1 的变量池：
- `../随机写真融合版/references/变量池-形象神态.md`
- `../随机写真融合版/references/变量池-服装场景.md`
- `../随机写真融合版/references/变量池-摄影语言.md`
- `../随机写真融合版/references/变量池-导演路线.md`
- `../随机写真融合版/references/成像机制原则.md`

随机时不是把抽中的词全部塞进去，而是先抽“摄影企划”，再让其他变量服从企划。

## 11. 批量差异

n>1 时，至少让每组在以下四项中的三项明显变化：场景、故事瞬间、焦段/机位、主成像系统。身份保持不变。用户锁定的条件不参与变化。

## 12. 输出

默认每组输出：简短标题/要素卡 + 中文完整 Prompt + 英文完整 Prompt + 精准负面词。用户说“只给提示词”时省略解释和要素卡。

Prompt 使用连贯自然语言，重要不可协商条件放前面。避免机械关键词汤和重复同义词。

## 13. 调用示例

- “孙琳雪随机写真4组” → Identity Lock 孙琳雪，四组摄影企划明显不同。
- “按这张脸，换成雨夜东京街头，CCD直闪” → 参考图只负责身份；场景、服装、动作按用户要求；CCD为唯一主成像系统。
- “保持人物和衣服，只换成35mm低机位旅行抓拍” → Identity + Outfit 锁定，只改镜头、构图、场景瞬间。
- “参考图1用脸，图2用衣服，图3用构图” → 明确三张参考图职责，不混合身份。
