# 随机写真融合版 V2｜自包含版

本 Skill 的所有依赖均位于本目录 `references/`。不要再访问 V1 跨目录路径。

## 核心优先级
用户明确指定 > 成年与安全限定 > 人物身份一致性 > 参考图职责 > 场景与故事瞬间 > 美姿 > 镜头 > 光线 > 成像系统 > 风格。

## 人物身份一致性
有参考人物图时，将参考图作为人物身份来源；这是同一个人物换场景拍摄。保持可识别的整体面部身份与比例，不用冗长的新五官描述与参考图竞争。摄影风格、妆容、灯光、焦段和服装只改变照片表现，不应重新设计人物脸。

首次换场景或用户反馈人物不像时，使用身份保护模式：优先正面到轻微转头；脸部主要结构清楚可见；减少大侧脸、严重遮挡、极端俯仰、脸部死黑和严重运动模糊。全身或远景仍要求脸部清晰可辨。

无参考图时才读取 `references/人物层.md`。

## 参考图职责
多张参考图先区分人物身份、服装、姿势、构图、光线、环境、风格。用户指定某图只参考衣服、姿势或场景时，不把该图当人物身份来源。

## 故事与美姿
优先正在发生的瞬间，一张图一个主要动作。未指定姿势或要求自然抓拍时读取 `references/人物美姿导演.md`；多组随机动作或动作去重时再读取 `references/美姿变量池.md`。

## 镜头
24–28mm 用于环境广角；35mm 用于生活纪实；50mm 用于自然中近景；85–135mm 用于人物突出与空间压缩；更长焦用于远距离观察。机位、距离与焦段保持一致。

## 光线与成像
光线按来源、方向、落点、结果组织，一张图只保留一个主光逻辑。每张图只选择一个主成像系统。需要详细成像规则时读取 `references/成像机制原则.md`。

## 冲突检查
生成前检查人物身份、脸部可见性、姿势可实现性、焦段与机位、主光、成像系统、服装天气动作和构图。冲突时保留用户明确条件与人物身份一致性。

## 本地 references 按需加载
默认不要一次读取全部文件：
- 人物文字锚点 → `references/人物层.md`
- 自然姿态 → `references/人物美姿导演.md`
- 多组随机美姿 → `references/美姿变量池.md`
- 随机服装或场景 → `references/变量池-服装场景.md`
- 发型、神态、状态 → `references/变量池-形象神态.md`
- 镜头与构图 → `references/变量池-摄影语言.md`
- 随机摄影企划 → `references/变量池-导演路线.md`
- 成像系统与光线一致性 → `references/成像机制原则.md`
- 用户明确要求模拟远距离抓拍感 → `references/偷拍感模式.md`

所有路径都从 `随机写真融合版-V2/references/` 读取。某文件读取失败时明确报告具体文件，不回退到 V1，也不假装已经读取。

## 随机导演
先选一个摄影企划，再让服装、场景、动作、焦段、光线和成像系统服从同一企划，不把随机词全部堆在一起。

## 批量差异
多组生成时，场景、故事瞬间或美姿、焦段或机位、主成像系统中至少三项明显变化；人物身份和用户锁定条件保持不变。

## 输出
默认每组输出简短要素卡、中文完整 Prompt、英文完整 Prompt 和精准负面约束。用户说只给提示词时省略解释。人物参考图任务的身份一致性要求放在 Prompt 前部。

## 加载纪律
少重复、按需读取。简单任务不套大流程；检查通过后停止额外加载。用户已经锁定的条件不再随机覆盖。
