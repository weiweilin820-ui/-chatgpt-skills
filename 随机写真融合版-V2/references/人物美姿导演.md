# 人物美姿导演

用于「随机写真融合版 V2」的人像姿态与动作导演模块。目标不是背诵固定 Pose，而是让动作符合人物、场景、镜头、服装和正在发生的瞬间，减少僵硬摆拍和“AI 模板手势”。默认仅用于明确成年人物。

## 1. 核心原则

美姿不是“手放哪里”的单点描述，而是按完整身体关系组织：

**动作动机 → 重心 → 躯干方向 → 肩胯关系 → 腿部结构 → 手部落点 → 头部角度 → 视线 → 表情 → 道具/环境互动 → 抓拍时刻。**

先决定人物正在做什么，再决定身体怎么呈现。不要先随机手势，再硬塞进场景。

## 2. 动作动机

优先选择有原因的动作：
- 刚停下脚步，重心还在转换。
- 听到有人叫她，回头到一半。
- 风吹乱头发，抬手整理发丝。
- 刚坐下，手还扶着椅缘。
- 拿起咖啡准备喝，视线却被窗外吸引。
- 下车后整理衣摆或包带。
- 翻书、取唱片、拿伞、拉窗帘、推门、扶栏杆、整理耳机。
- 走动中回看镜头，而不是站定后摆拍。

除非用户明确要求棚拍/硬照，否则避免“正面对镜头站直、双手固定摆姿”。

## 3. 重心设计

### 站姿
优先使用非对称重心：60/40、70/30 或单腿承重。承重腿相对稳定，另一腿自然放松、前点、后撤、轻弯或跨步。

避免：两腿完全平行、膝盖锁死、脚尖机械同向。

### 坐姿
先决定坐深还是坐浅：
- 坐浅：更有张力，适合桌边、吧台、车内、床沿。
- 坐深：更松弛，适合沙发、窗边、休息状态。

骨盆方向和肩膀方向允许轻微错开，避免全身像证件照一样正对镜头。

### 蹲姿/跪姿
必须说明支撑关系，确保姿态可实现。避免双腿、脚踝、膝盖同时出现不可能的折叠。

## 4. 躯干与肩胯

身体可以有轻微 S 形，但不要夸张到时装插画式折腰。

常用关系：
- 肩与胯轻微反向，产生自然扭转。
- 一侧肩膀略低，配合单腿承重。
- 身体略侧，脸回向镜头，形成“身体不迎合镜头、脸才回应镜头”的抓拍感。
- 行走、回头、取物时允许躯干处于动作中间状态。

## 5. 腿部线条

腿部首先服务动作与重心，其次才是视觉线条。

可选结构：
- 一腿承重，另一腿脚尖轻点地。
- 前后错步，形成纵深。
- 行走中一腿向前，后腿尚未完全离地。
- 坐姿双腿自然并向一侧。
- 一腿屈、一腿伸，但膝盖方向必须符合人体结构。
- 台阶或栏杆场景可让一只脚处于高低差。

避免：为了“显腿长”无限拉伸肢体、双腿异常交叉、膝盖朝向与脚尖完全冲突。

## 6. 手部落点

手是最容易出现模板感和生成错误的区域。优先让手“有事可做”。

自然落点优先级：
1. 与道具互动：手机、饮料、书、唱片、包带、伞、耳机、门把手、栏杆。
2. 与自身衣物互动：整理袖口、衣摆、领口、包带、头发。
3. 与环境互动：扶桌、靠椅背、碰窗框、扶车门。
4. 无任务时：一只手自然下垂，另一只手落在口袋、腿侧、桌面或腰旁。

避免：两只手同时摸脸、双手同时整理头发、五指刻意完全张开、手掌正对镜头、无理由悬空。

## 7. 头部与视线

头部角度只需小幅变化：微低、微仰、轻侧、回头到一半。

视线类型：
- 看镜头：更直接、更适合时尚硬照或亲密手机感。
- 看镜头旁：更自然，像刚注意到拍摄者。
- 看环境中的对象：增加故事性。
- 低垂视线：适合安静、阅读、整理物品。
- 远望：适合旅行、窗边、海边、大环境。

眼睛方向必须和头部、动作逻辑一致。

## 8. 表情

优先微表情，不强行“大笑”：
- 若有若无的浅笑
- 放空
- 专注
- 刚意识到镜头的轻微惊讶
- 忍笑
- 疲惫但放松
- 安静观察
- 轻微皱眉思考

除非用户要求，避免“标准商业微笑 + 正视镜头 + 站直”组合。

## 9. 抓拍时刻

为减少摆拍感，优先选择动作的 30%–70% 中间帧，而不是动作完成后的终点：
- 手刚抬到头发旁，而不是已经摆好摸头姿势。
- 回头到一半，而不是完整扭头等待拍照。
- 刚跨出一步，而不是双脚并拢停住。
- 杯子刚离开桌面，而不是端在嘴边摆拍。

## 10. 镜头与美姿联动

### 广角 24–35mm
动作可以更大，允许前后腿产生透视差、手臂进入前景、人物与环境互动更多。避免把脸放到画面边缘导致畸变。

### 标准 50mm
动作幅度中等，以自然站姿、坐姿、转身、轻互动为主。

### 中长焦 85–135mm
动作更克制，强调肩颈、视线、手部细节和轮廓；不需要夸张跨步。

### 远距离抓拍 135mm+
人物通常不知道镜头存在，动作应由场景驱动：走路、等车、看店铺、整理物品、与环境互动。

## 11. 景别与美姿联动

- 特写：只描述头、肩、手部可见动作，不要塞完整腿部姿势。
- 半身：重点是肩胯、手、头部与道具。
- 3/4 身：可加入腿部重心和一步动作。
- 全身：必须明确脚的位置、承重关系和空间接触。
- 大环境人物：动作描述要简洁高信号，避免细小手势成为无效噪音。

## 12. 服装适配

姿态必须服从服装结构：
- 长裙/汉服：适合转身、行走、扶裙摆、风吹衣摆，避免复杂盘腿导致布料结构混乱。
- 短裙/JK：优先正常站立、走动、坐姿、扶包带；避免不自然的大幅抬腿。
- 西装/风衣：适合插袋、整理袖口、扣衣、转身、走动。
- 家居服：姿态更松弛，适合靠坐、伸展、抱杯、听音乐。
- 高跟鞋：步幅适中，重心更清晰，避免大幅跳跃或不稳定蹲姿。

## 13. 场景适配

- 街头：走路、等灯、看橱窗、收伞、整理包带。
- 咖啡店：拿杯、翻书、望窗外、拉椅子、起身。
- 车内：系安全带、看窗外、拿饮料、调整座椅、刚下车。
- 唱片店/书店：取物、翻阅、低头寻找、回头回应。
- 海边/山景：扶栏杆、迎风、走动、眺望，不必总张开双臂。
- 卧室/家居：坐床沿、靠窗、整理耳机、拿水杯、阅读。
- Editorial：允许更明确的几何肢体线条，但仍保持关节结构可信。

## 14. 随机姿态生成流程

当用户没有指定姿势时，按以下顺序随机：
1. 先选动作动机。
2. 决定站/坐/走/蹲/靠。
3. 决定承重和身体朝向。
4. 决定一只主要动作手。
5. 另一只手只做辅助或自然放置。
6. 决定头部和视线。
7. 决定表情。
8. 最后检查是否与镜头、服装、场景冲突。

一次只保留一个主要动作。不要把“走路 + 坐下 + 回头 + 喝咖啡 + 整理头发”塞进同一帧。

## 15. 防模板重复

连续多组写真时，不要只替换“左手/右手”。至少改变以下三项：
- 重心结构
- 身体朝向
- 主动作
- 视线对象
- 手部任务
- 与环境的接触方式

避免高频重复：摸头、托腮、双手背后、手扶脸、固定歪头、剪刀手。

## 16. 解剖与可实现性检查

生成 Prompt 前检查：
- 承重腿与骨盆方向合理。
- 两只手各自有明确归属，没有多余手臂。
- 手指不被描述成复杂交叉结构。
- 膝盖、脚尖方向基本一致。
- 没有同时“背对镜头”和“胸口正对镜头”等矛盾。
- 坐姿必须有真实支撑面。
- 服装不会因为动作产生明显不可能的结构。

## 17. 输出写法

不要输出人体工程学说明，最终 Prompt 应转换成自然摄影语言。例如：

“她刚从窗边转身，重心落在右腿，左脚向前轻点，肩膀与胯部略微错开；右手还握着刚拿起的咖啡杯，左手自然垂在裙侧。她像是听见有人叫她，头只回了一半，目光刚刚落到镜头附近，嘴角有一点忍不住的笑意。”

而不是：

“70/30 重心、contrapposto、S 曲线、肩胯反向、手部动作 A。”

内部可以结构化，输出必须像真实摄影导演在描述一个瞬间。
