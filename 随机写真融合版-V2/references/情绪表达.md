# 情绪表达

每张导演卡建立一条三段式微叙事：`事件 → 即时生理/动作反应 → 可读情绪`。

## 写法

1. 事件必须具体且可在一帧内理解，如冰饮碰到腰侧、风吹走票根、袖口被门把轻挂、唱片刚好跳针。
2. 反应必须小而真实，如肩膀轻缩、手腕停住、呼吸一顿、身体重心偏移。
3. 情绪只选一个主方向，可带一个次方向，如惊讶后失笑、困倦中放松、疏离里短暂柔软。
4. 只设置一个主要互动对象，避免同时拿手机、饮料、书和包。
5. 动作应像事件发生中被捕捉，不写成“为展示身材而摆姿势”。

## 指向写法

不要单独设“视线”栏。将视觉指向自然写入其他块，例如：

- 表情：她抬眼看向拍摄者，刚好被逗笑。
- 动作：她侧身整理袖口，余光落向镜头。
- 构图：镜头捕捉她回头的一瞬，五官保持清晰。
- 非直视：她看向自动售货机亮起的按钮，脸部仍处在主光内。
