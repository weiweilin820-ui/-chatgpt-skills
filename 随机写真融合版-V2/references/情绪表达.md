# 情绪表达

情绪是独立随机变量，与场景、动作、姿势、服装和机位分别抽取，再做兼容修正。

## 核心规则

1. **只写情绪，不拆解表情肌肉。** 输出只使用“开心、悲伤、憔悴、难过、惊慌”等语义状态，不描述嘴角角度、露几颗牙、眉毛抬多高、眼睛睁多大、苹果肌变化、鼻翼变化、具体嘟嘴形状等。
2. **不建立独立【表情】字段。** 情绪只作为 `场景与动作` 中的一句短语，例如：“人物呈现明显的惊慌情绪，但保持人物身份与五官结构稳定。”
3. 每张卡默认一个主情绪；必要时允许一个自然过渡的次情绪，例如“惊讶后放松”“疲惫中释然”，但不要堆叠三种以上情绪。
4. 情绪需要与当前事件、自拍状态或环境相容，但不必永远是“开心”。日常、自拍、旅行、工作、神话、灾变、动物互动都可以出现不同情绪。
5. 情绪幅度可分为轻微、明显、强烈三档。即使强烈，也只写情绪词和强度，不描述夸张面部动作。身份一致性优先。
6. 当用户明确测试情绪或脸部稳定性时，优先使用胸像近景、肩部以上近景或半身近景，让脸部成为绝对视觉主体。
7. 自拍、镜子自拍、同行者拍摄、摆姿势拍照都可以承载情绪，不要求人物必须“正在做某项工作或任务”。

## 情绪池

### 明亮 / 正向
开心、愉悦、惊喜、期待、好奇、俏皮、得意、害羞、放松、温柔、释然。

### 中性 / 内收
平静、专注、若有所思、克制、警觉、倔强、冷淡、怀疑、困惑、无奈、恍惚。

### 低落 / 疲惫
疲惫、憔悴、失落、悲伤、难过、委屈、孤独、怅然。

### 紧张 / 高唤醒
担忧、紧张、惊慌、害怕、震惊、烦躁、生气。

## 场景兼容示例

- 自拍 / 镜子自拍：开心、俏皮、得意、害羞、疲惫、憔悴、冷淡、若有所思。
- 动物互动：开心、好奇、惊喜、无奈、担忧。
- 雨夜 / 深夜 / 独处：疲惫、憔悴、失落、怅然、孤独、平静。
- 旅行 / 新奇发现：期待、好奇、惊喜、释然、愉悦。
- 突发异常 / 超现实事件：困惑、震惊、惊慌、警觉、好奇。
- 追逐 / 逃离 / 灾变：紧张、惊慌、害怕、担忧、倔强。
- 工作 / 手作 / 研究：专注、平静、若有所思、困惑、释然。

这些只是兼容提示，不是固定绑定。允许产生有趣但合理的反差，例如华丽场景里的疲惫、自拍时的冷淡、动物恶作剧后的无奈。

## 推荐写法

- “人物呈现轻微的开心情绪。”
- “人物带有明显的惊喜与好奇。”
- “人物呈现疲惫、略显憔悴的状态。”
- “人物带有难过和失落的情绪。”
- “突发状况让人物呈现明显的惊慌情绪。”
- “人物带有克制而警觉的情绪状态。”
- “人物看向镜中自己，呈现若有所思的情绪。”

## 禁止写法

不要写：

- 嘴角上扬多少
- 是否露齿以及露出几颗牙
- 眉毛抬起或下压多少
- 眼睛睁大、眯眼的具体幅度
- 苹果肌抬升
- 鼻翼扩张
- 嘟嘴的具体唇形参数
- 为了表达情绪而改变脸型、五官比例或标志性痣

让模型依据情绪词自然完成表情，同时始终服从人物身份锁定。
